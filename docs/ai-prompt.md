# AI に予定を作ってもらうプロンプト

ChatGPT・Claude・Gemini などの AI に予定を話し言葉で伝えて、RE:main に取り込める JSON を作ってもらうためのプロンプトです。JSON の細かい仕様は [json-format.md](json-format.md) にあります。

## 使い方

1. RE:main の右上 →「ファイルと設定」→「インポート」→「AI 用のプロンプトをコピー」を押す
   - 今日の日付・2週間分の曜日表・今あるリストが入った状態でコピーされます
   - アプリを開けないときは、下のプロンプトをコピーし、`{{TODAY}}` `{{CALENDAR}}` `{{LISTS}}` を自分で書き換えてください（`{{LISTS}}` は `[{"id":"inbox","name":"リマインダー","color":"blue"}]` のままで構いません）
2. AI のチャットに貼り付け、最後の「予定:」のあとに予定を書いて送る（例:「毎週火曜と金曜の朝7時半に燃えるゴミ、明日15時に歯医者、毎月25日に家賃」）
3. AI が返した JSON をコピーし、RE:main の「ファイルと設定」→「インポート」の欄に貼り付けて「貼り付けた JSON を取り込む」
   - 「今のデータに追加」のまま取り込めば、今あるリマインダーはそのまま残ります

うまく取り込めないときは、表示されたエラー文をそのまま AI に貼って「直して」と頼んでください。

## プロンプト

アプリの「AI 用のプロンプトをコピー」は、下の枠の中身をそのまま使います（`npm run build` でアプリに埋め込まれます。直すときはここを編集してください）。

# 前提

{{CALENDAR}}

# 出力のしかた
- ```json のコードブロックを1つだけ出す。コードブロックの外には、読み取り方の短い確認（1件1行、「毎週火・金 7:30 燃えるゴミ」のように）だけ書く。
- 日時がどうしても決められないものだけ、JSON を出す前に質問する。それ以外は下の決まりで補って、聞かずに作る。
- JSON はコメントや末尾カンマを入れない、正しい JSON にする。

# JSON の形
{
  "format": "rimain.reminders",
  "version": 1,
  "lists": [ { "id": "inbox", "name": "リマインダー", "color": "blue" } ],
  "reminders": [ ... ]
}
- lists には「今あるリスト」をそのまま入れる。新しいリストが必要なら追加する（id は英小文字の短い語、color は blue / red / orange / green / teal / purple / indigo / gray のどれか）。
- 日時はすべて日本時間で "YYYY-MM-DDTHH:mm"（例 "2026-10-25T18:30"）。秒・タイムゾーン・"Z" は付けない。日付だけは "YYYY-MM-DD"。
- 曜日の番号: 0=日 1=月 2=火 3=水 4=木 5=金 6=土。時刻は "HH:mm"（例 "07:30"）。

# リマインダー1件の項目
必須は title だけ。使わない項目は書かない。
- "title": 通知に出る短い文（例 "燃えるゴミを出す"）
- "notes": メモ（任意）
- "url": 通知をタップしたときに開く https の URL（任意）
- "list": 入れるリストの id（省略すると lists の先頭）
- "due": 通知する日時。単発の予定では必ず書く。繰り返しでは書かない（アプリがルールから最初の日時を計算する）
- "rule": 繰り返しのルール（下記）。単発なら書かない
- "nag": 完了するまで再通知するとき { "every": 分 }（1〜120。「確実に」「しつこく」なら { "every": 5 }）
- "flagged": フラグを付けるなら true
- "priority": 優先度 0〜3（「大事」「重要」なら 2）

# 繰り返し（rule）
共通の項目:
- "freq": 下のどれか（必須）
- "interval": 何回ごとか（1 なら省略。隔週・隔日・隔月は 2。「N日おき」は N+1、「N日ごと」は N）
- "times": 通知する時刻の配列（例 ["08:00","20:00"]。省略すると 9:00）
- "start": この日から始める "YYYY-MM-DD"（「来月から」「11/1から」のときだけ）
- "until": この日まで "YYYY-MM-DD"、"count": この回数まで
- "skipHolidays": true で祝日は通知しない
- "onlyDays": 曜日の番号の配列。daily / parity などで「平日だけ」等に絞る（例 [1,2,3,4,5]）

freq ごとの書き方:
- 毎日・隔日・N日ごと: { "freq": "daily", "interval": 2, "times": ["21:00"] }
- 毎週・隔週（曜日を指定）: { "freq": "weekly", "byDay": [2,5], "times": ["07:30"] }
- 平日: { "freq": "weekly", "byDay": [1,2,3,4,5] }（「祝日除く」「祝日は休み」なら "skipHolidays": true を足す）
- 毎月 N 日: { "freq": "monthly", "byMonthDay": [25] }（月末は -1。複数日は [1,15]）
- 毎月 N 日、土日祝なら前の平日: 上に "bizBefore": true を足す
- 毎月 第N ○曜日: { "freq": "monthly", "byNth": { "n": 2, "wd": 2 } }（最終○曜日は n: -1）
- 毎年: { "freq": "yearly", "byMonth": 3, "byMonthDay": [10] }
- 偶数日・奇数日: { "freq": "parity", "parity": "even" }（奇数は "odd"）
- N 時間ごと: { "freq": "hourly", "interval": 3 }、N 分ごと: { "freq": "minutely", "interval": 30 }（"times": ["09:00"] で開始時刻）
- 完了してから N 後: { "freq": "afterDone", "interval": 1, "unit": "month" }（unit は minute / hour / day / week / month / year）

# 時間差で順番に通知するグループ
「9時から 千葉、東京、神奈川を30分おき」のように、1つの用事を時間差で順に知らせたいときだけ使う。
{ "kind": "group", "title": "まとめの名前", "due": "最初の通知日時", "spacing": "equal", "every": { "value": 30, "unit": "minute" },
  "steps": [ { "title": "千葉" }, { "title": "東京" }, { "title": "神奈川" } ] }
- unit は minute / hour / day。間隔が項目ごとに違うときは "spacing": "each" にして、各 step に "after": { "value": 25, "unit": "minute" }（ひとつ前からの間隔。1件目は 0）を書く
- グループには rule と nag は使えない

# あいまいな言い方の決まり
- 「祝日除く」「祝日はなし」「祝日は休み」→ "skipHolidays": true
- 時刻なし → 9:00。朝 8:00、昼 12:00、おやつ 15:00、夕方 17:00、仕事終わり・帰り 18:00、夜・晩 20:00、寝る前 22:00、起きたら 7:00
- 「明日」「来週金曜」などは今日と曜日表から計算する。「週明け」は次の月曜
- 単発の due は今より後にする。今日の時刻がもう過ぎていれば明日にする
- 年が書かれていない日付は、今日以降で一番近いその日
- 「〜の3日前に」のような前もっての通知は、その日時を due にして title に元の予定を書く（例「3日前: 車検」）
- 1つの文に予定が複数あれば、別々のリマインダーにする

  ]
}
```
